Compression accounting: conditional vs total

All headline BPB numbers are conditional (decoder already has the model). A carry-less 32-bit range coder driven by the model probabilities achieves actual ≈ ideal (within 0.5%) and was verified byte-for-byte exact on real files.

Including the model itself (12.2M params = 48.8 MB fp32 weights + 0.25 MB tokenizer; the 146 MB .pt on disk also stores optimizer state, not needed for inference): total BPB(N) = 0.708 + 8·49 MB / N. Crossover vs xz-6 on in-domain code at N ≈ 250 MB — at 1 GB total ≈ 0.91 BPB vs xz 1.51; at 10 GB ≈ 0.73. On small corpora (<50 MB) the model cost dominates and xz wins. The stacked bar in the chart above shows exactly this.

Method

Data & contamination

torvalds/linux pinned at ffc2532 (v6.6), shallow sparse checkout, .c/.h only. Splits are never token-random: held-out subsystems (mm/fs/net/crypto/security/sound/virt), held-out driver families (gpu/net/media/staging), seeded file-level val split grouped by content hash so exact duplicates never straddle splits. Byte-level BPE-4096 trained on train split only, verified lossless. 13 external repos pinned by revision for evaluation only.

Metrics

PPL = exp(mean CE); BPB = NLL / (ln 2 · bytes); ideal ratio = 8/BPB. Documents evaluated independently — no cross-file context, no padding in the loss, first token of each file excluded. Baselines: gzip/zstd/xz/bzip2 on identical corpora with consistent archive framing.

Hardware

RTX 2060 (Turing, sm_75, 6 GB): FP16 autocast + GradScaler (no native BF16, no FlashAttention). Benchmarked: tiny 16×1024 = 1.85 GB / 151k tok/s; small 16×1024 = 3.13 GB / 72k tok/s; medium 8×1024 = 2.7 GB / 35k tok/s (8×2048 OOMs). Xeon E3-1245 v3, 16 GB RAM.

Training

AdamW, cosine LR with warmup, grad clip 1.0, grad accumulation; checkpoints every 500 steps with resume (verified — survived a machine freeze mid-run). JSONL logging of loss/LR/grad-norm/tok/s/VRAM/FLOPs.

Reproduce

git clone <this repo> && cd kernel-lm
uv pip install --python ../.venv/bin/python3 -r requirements.txt
python3 scripts/prepare_data.py        # pinned kernel -> manifest + splits
python3 scripts/train_tokenizer.py     # BPE-4096 on train split, lossless check
python3 scripts/tokenize_data.py       # memmap token arrays
python3 scripts/overfit_test.py        # correctness: must overfit a small batch
python3 scripts/benchmark_gpu.py       # VRAM/throughput sweep for 6 GB
python3 train.py --config configs/small.yaml --run-name small-8k --max-steps 8000
python3 evaluation/perplexity.py --checkpoint checkpoints/small-8k/latest.pt --corpora data/tokens data/eval_tokens
python3 evaluation/compression.py --checkpoint ... --files <some .c files>   # byte-exact range coding
python3 scripts/sample_batch.py --max-new-tokens 768 --real-prefixes 6          # free samples
